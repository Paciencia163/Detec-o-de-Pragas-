# 🐛 Detecção de Pragas com Visão Computacional e YOLO

Bem-vindo ao **Detecção de Pragas com Visão Computacional e YOLO** — um aplicativo inteligente Streamlit projetado para ajudar agricultores a detectar pragas usando **YOLOv8** e **Visão Computacional**.  
Esta aplicação aproveita o poder da inteligência artificial (IA) para oferecer detecção de pragas em tempo real a partir de imagens, vídeos e feeds de webcam ao vivo, tornando-se uma ferramenta essencial para o gerenciamento eficaz de pragas na agricultura. Este protótipo é desenvolvido como parte de um trabalho sobre **DESENVOLVIMENTO DE UM SISTEMA PARA MONITORAMENTO AGRÍCOLA UTILIZANDO DEEP LEARNING INTEGRADO EM UM DRONE**.

## 🚀 Funcionalidades

- **Detecção de Objetos YOLOv8** para detecção precisa e rápida de pragas 🤖
- Detecte pragas em **imagens**, **vídeos** e **streams de webcam em tempo real** 🎥
- **Sistema de login seguro** com criptografia de senha 🔐
- Interface de usuário simples e **interativa** alimentada por **Streamlit**
- Navegação fácil de usar com controles claros e intuitivos 📱
- Design bonito com **página de login animada** 🌿

---

## 🛠️ Pilha Tecnológica

- [Python 3.10+](https://www.python.org/)
- [Streamlit](https://streamlit.io/) — para o framework da aplicação web
- [OpenCV](https://opencv.org/) — para processamento de imagens e vídeos
- [Ultralytics YOLOv8](https://docs.ultralytics.com/) — para detecção de objetos (pragas)
- [Hashlib](https://docs.python.org/3/library/hashlib.html) — para hash seguro de senhas
- [SQLite](https://www.sqlite.org/) — para gerenciamento de banco de dados (banco de dados relacional incorporado e leve)

## 🛠️ Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/Detecção-de-Pragas-com-Visão-Computacional-e-YOLO.git
   cd Detecção-de-Pragas-com-Visão-Computacional-e-YOLO
   ```

2. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Execute o aplicativo:**
   ```bash
   streamlit run Deployement/app.py
   ```

---

## 📖 Uso

1. Abra o aplicativo no navegador.
2. Faça login ou crie uma conta.
3. Navegue pelas seções: Início, Detecção, Recomendação de Fertilizante.
4. Faça upload de imagens/vídeos ou use a webcam para detecção de pragas.
5. Receba recomendações de fertilizantes com base nos dados inseridos.
